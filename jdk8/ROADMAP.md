# 剩余工程与阶段验收

固定基线与当前完成标记沿用 PROGRESS.md 的 `jdk8-m14`。整体目标仍未完成。单个里程碑通过不代表整个项目结束；排除项只有用户指定的 Guardrails、Spring Boot Starter、Jackson 3。

## 全量范围

[模块清单](MODULE-INVENTORY.md) 枚举基线全部 POM，[机器可读清单](MODULE-INVENTORY.json) 保留每个模块的直接依赖声明与模型/向量库源码候选证据。其他分类尚须人工核对；清单不构成依赖 Java 8 审计，更不代表功能通过。新增 SQLite 属于本分支扩展，单独记录于现有支持矩阵。

## 执行顺序

1. MCP：stdio 与子进程生命周期；资源、模板、提示词、日志、进度、工具/资源/提示词缓存变更；HTTP 与 stdio 端到端及独立 BOM 消费。第十阶段 jdk8-m10 已通过，精确范围与剩余限制见进度和阶段快照。
2. MCP：Registry 在 jdk8-m11 按固定基线六个同步 API 验收；WebSocket/WSS 在 jdk8-m12 完成上述子集；现代 HTTP 在 jdk8-m13 完成发现/订阅/异步续传子集；现代 stdio/WebSocket 在 jdk8-m14 完成专项；继续旧双端点及其余基线能力；逐能力验证会话、取消、超时、恢复和释放。自动恢复不重发原工具请求。
3. Agentic：四模块 187 个生产文件的声明级清单已记录于 [AGENTIC-AUDIT.md](AGENTIC-AUDIT.md)；当前主模块已有 release 8 / 真实 Java 8 基础 WIP 与二进制 API 对照，见 [AGENTIC-PORT.md](AGENTIC-PORT.md)；完整能力验收及其余三模块仍 pending。继续主模块全量回归、记忆/挂起恢复、错误/取消/生命周期、planner/supervisor/声明式等全部能力及其余依赖审计。逐能力记录实现和验收，不能用最简单的顺序示例代替完整支持。
4. 模型与向量库：从完整清单逐模块推进；解析有效 POM 与传递依赖、确认 Java API/字节码，再实现并以本地模拟服务验收功能。只审计、只编译或声明不支持不计完成。新发现模块补入清单，不隐式排除。
5. 总体验收：所有纳入模块的 clean 构建、实际 Java 8、原有回归/TCK、独立 BOM 消费、字节码/API/链接审计；迁移说明、支持矩阵、已知限制、结果快照、Git 提交和最终标签齐全后，逐项核对整体目标。
